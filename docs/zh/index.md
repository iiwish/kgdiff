# kgdiff 是什么？

kgdiff 是知识图谱的 `git diff`。给它一张图的两个版本（一次本体发布、一次 GraphRAG 抽取、一张数据血缘 DAG），它会按审阅者的思路告诉你发生了什么：某个术语合并进了另一个，某个类挪到了新的父类下，某条关系改为指向别处，某个标签改了名。结果可以输出在终端里，可以作为 Pull Request 评论，也可以放进交互式查看器：两个版本画在同一张稳定的地图上。

## 为什么不用文本 diff？

文本 diff 比较的是文件。在 Turtle 里给一个类改名，所有提到它的行都会变；把两个术语合并，看到的是一处删除加上散落在文件各处的修改；把同一张图重新序列化一遍，看起来就像全都变了。kgdiff 比较的是图本身：

- **跨版本匹配节点**：按 id，按替代声明（例如 OBO 的 `replaced_by`），或者在 id 没有意义时（例如两次 LLM 抽取的结果）按标签和邻居结构匹配。
- **给变化分类**：改名、更换 id、类型、同义词、属性、废弃、在层级中迁移、合并、拆分、关系改指向和谓词变化。
- **把变化分组**：每组对应审阅者要做的一次判断，按便于阅读的顺序排列：先清理（删除），再重组（结构调整），再细化（修改），最后生长（新增）。
- **忽略无关的差别**：同一张图写成 Turtle 还是 N-Triples，语句按什么顺序排列，比较结果都完全相同。

## 用法一览

| 你想要……                       | 用什么                                                                 |
| ------------------------------ | ---------------------------------------------------------------------- |
| 看两个文件之间变了什么         | 命令行：[快速开始](./getting-started.md)                               |
| 在每个修改图谱的 PR 上说明变化 | [GitHub Action](./guide/ci.md)，或在其他 CI 中运行命令行               |
| 直观地浏览差异                 | HTML 报告（`-o report.html`）或 [Playground](/playground.html?lang=zh) |
| 在自己的应用里展示差异         | [`<kgdiff-viewer>` Web 组件](./guide/viewer.md)                        |
| 在代码里比较图                 | [各个库](./guide/library.md)                                           |

### 装哪个包

多数人只需要一个包，按你想做的事来选：

| 你想要……                       | 安装                                                                    |
| ------------------------------ | ----------------------------------------------------------------------- |
| 在终端或 CI 里比较图谱文件     | `@kgdiff/cli`（`npx @kgdiff/cli a.ttl b.ttl`），或者 GitHub Action      |
| 在网页里展示差异，不写渲染代码 | `@kgdiff/viewer`（`<kgdiff-viewer>` Web 组件）                          |
| 在代码里计算差异，自己画       | `@kgdiff/core` 和 `@kgdiff/compute`，再按需加 `layout`、`scene` 或 `g6` |

`@kgdiff/cli` 运行的是原生程序：npm 会随它一起装上适合本机的那一个（`@kgdiff/cli-darwin-arm64`、`@kgdiff/cli-linux-x64-gnu` 等），不需要自己安装这些平台包。各个库包的作用见[库](./guide/library.md)。

kgdiff 读取 RDF（Turtle、N-Triples、N-Quads、TriG、RDF/XML、JSON-LD）、OBO 和常见的 JSON 图格式（[格式](./formats.md)）。一切都在本地运行：命令行在你的机器上，Playground 和查看器在你的浏览器里，不会上传任何数据。
