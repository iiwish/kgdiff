`@kgdiff/cli` runs the native kgdiff, written in Rust (RFC 0002, phase 4), instead of the TypeScript CLI, which is removed. It prints the same bytes for the same arguments (every run of the conformance corpus is checked on Linux, macOS and Windows). The package is now a small launcher: npm installs the binary of your platform with it as an optional dependency (`@kgdiff/cli-darwin-arm64`, `-darwin-x64`, `-linux-x64-gnu`, `-linux-x64-musl`, `-linux-arm64-gnu`, `-linux-arm64-musl` or `-win32-x64`; Windows on Arm runs the x64 build), so an install with `--omit=optional` has no binary to run and says so, and `KGDIFF_BINARY` points the launcher at another one. The same kgdiff is on crates.io (`cargo install kgdiff`). Breaking: the package no longer exports a JavaScript API (`main`, `renderSummary`, `renderMarkdown`, `buildReportHtml`, …); diff in JavaScript with `@kgdiff/core` and `@kgdiff/formats`, and in Rust with the `kgdiff` and `kgdiff-report` crates. The bug report link of an unexpected error names the platform and architecture, no longer a Node.js version.
